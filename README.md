# FinoktAI Website

## Project info

This repository contains the FinoktAI marketing website built with Vite, React, TypeScript, shadcn-ui, and Tailwind CSS.

## Development

- Requirements: Node.js and npm
- Install dependencies:
```
npm install
```
- Start dev server:
```
npm run dev
```

## Build
```
npm run build
```
The production build is output to the `dist/` directory.

## Deploy
Deploy the contents of `dist/` to your static host (e.g., GitHub Pages). Ensure:
- `CNAME` file contains `finokt.com` for custom domain.
- `public/404.html` is included for SPA routing fallback.

## Tech Stack
- Vite
- React + TypeScript
- shadcn-ui
- Tailwind CSS
